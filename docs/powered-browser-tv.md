# Powered Browser Television

From ELN 3.0.60 this device is provided by the optional [EA Media addon](https://github.com/reamnet/EAMedia).

See the [current device guide](https://github.com/reamnet/EAMedia/blob/main/docs/powered-browser-tv.md)
and [installation and building](https://github.com/reamnet/EAMedia/blob/main/docs/building.md).
Existing saved IDs and settings remain compatible.
